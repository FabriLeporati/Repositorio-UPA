## La idea (primer día)
Un juego de preguntas de opción múltiple sobre la historia del Paraguay para **2 jugadores**
que se van turnando en la misma computadora, todo por consola.

Lo que pensamos hasta ahora:
- Antes de empezar se elige un nivel: Fácil, Medio o Difícil.
- Se sortea quién empieza y se hacen 8 preguntas (4 para cada uno), alternando.
- Cada acierto vale 1 punto.
- Si quedan muy parejos queremos hacer algún desempate.
- El que pierde tiene que hacer una "penitencia" (para que sea más divertido jugarlo entre amigos).
